# Folder overview

This folder contains setup guidance for the BYU-Idaho eBadge, a customizable,
programmable electronics badge used for hands-on learning. The ESP32-S3
MicroPython examples have been archived under [`old/python/`](../../old/python/).

See [README.md](README.md) for setup instructions and instructions for copying
and running the archived examples.

For broader project documentation, hardware, firmware, and software, see the
[BYU-Idaho eBadge repository](https://github.com/BYU-I-eBadge/e-badge).
